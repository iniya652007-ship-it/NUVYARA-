# NUVYARA — Development Friction Log

## Challenges Encountered

- **Android Studio:** Gradle sync, manifest processing, and resource errors slowed development.
- **Android TV Emulator:** Slow startup and performance made testing difficult.
- **AWS Integration:** Connecting the Android application to AWS Lambda through Amazon API Gateway required endpoint testing and verification of the JSON response.
- **Remote Navigation:** Testing directional navigation and displaying the AWS reflection required debugging.

## Lessons Learned

These challenges helped me improve my Android troubleshooting skills, understand Android TV testing, and connect a Java application to a cloud backend using AWS Lambda and API Gateway.

## Current Status

The NUVYARA prototype runs in the Android TV emulator and displays the reflection returned by the AWS endpoint.
